RegisterBench | Multi-ink registration observation

Print proof review · Values are manually entered; the tool does not diagnose a press or prescribe corrections.

Start with a proof

Enter the position of the comparison ink relative to the reference ink at the same mark. Use millimetres: positive X = right; positive Y = down. The four marks are TL, TR, BL and BR. Both numbers are required for a complete observation.

The preloaded sample is fictional. Use “New blank review” before recording real measurements. No autosave and no network requests.

What this is not

Not a registration-mark generator, calibration system, press controller, pass/fail certification, or a method for finding the cause of a mismatch. Measurements must be taken consistently by the user.

Project reference

Measured proofs

Measurements are signed offsets of comparison ink minus reference ink. Empty pair = not measured, not zero. A partially filled pair does not enter summaries. Maximum 12 proof sheets, four positions each, values −25 to +25 mm.
